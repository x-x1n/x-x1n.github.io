Echoes of Memories

This is the overview & navigation site for the project Echoes of Memories.

It is recommended to access the websites on your PC, as certain function may not work well on mobile phones. It also requires a network environment that can access Github (e.g., eduroam), otherwise the website may not be fully loaded.

Each product of the project is distributed on different platforms (social media/webpage/physical booklet); However, for the convenience of viewing, they are all accessible under this web domain. Therefore, this project is still a transmedia one, rather than a multimedia one.

For the same reason (convenience for viewing), the navigation bar above will be displayed in every website. However, it should not be considered as a part of the product, and each product provides their own means to access other products.

Note on AI & Copyright & Ethics: the coding of this website has utilised AI tools. The rest part of the project (video/recorded sound/booklet design/soundmap SVG/etc.) does not contain AI work, and are all made/recorded by myself.
The background music of the video comes from a Youtube video. As this project is for nonprofit use in the field of education, it aligns with Youtube's Fair Use of Copyrights, and thus the project should not be considered as an infringement of copyright.
The video product does not contain human actors/participants to be specifically filmed, and the locations filmed in the video are within the campus. Therefore, it does not violates university's regulation on ethics, and does not require to complete IC Project Ethic Form.
